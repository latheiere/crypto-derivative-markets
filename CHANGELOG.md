# Changelog

This project follows Semantic Versioning for the Python distribution. Wire contracts carry their own
schema-major identifiers.

## Unreleased

No unreleased changes.

## 0.1.0 - 2026-08-10

### Added

- Provider-independent instrument descriptors, complete profiles, classification, and scenario keys.
- Protocol-scoped opaque native identity references with exact selectors and ambiguity-safe
  selection.
- Capability-specific structured assessment for incomplete economic metadata.
- Canonical open-interest and funding datapoint definitions with ordered calculation lineage.
- Context-independent open-interest conversion paths with stable formula identifiers, exact-ratio
  precision handoff, and explicit missing or unmodeled outcomes.
- Funding sample and interval evidence contracts that do not substitute retrieval time or inferred
  bounds for absent source metadata.
- Versioned JSON Schemas, strict codecs, bundled conformance vectors, and Antora documentation.
